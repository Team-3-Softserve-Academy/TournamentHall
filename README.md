# TournamentHall
A tournament hall comissioned by the family of Baelor

## Requirements

- Python 3.11+
- PostgreSQL (connection settings in `.env`, see `.env.example`)

```bash
python -m venv venv
pip install -r requirements.txt
```

Dependencies are pinned in `requirements.txt`. To add or update a package: install it, check the app, then run `pip freeze > requirements.txt` and update `pyproject.toml` if it is a direct dependency.

# DB Migrations
```bash
alembic upgrade head                            # apply all migrations (fresh DB or update)
alembic current                                 # show current revision
alembic revision --autogenerate -m "message"    # create a migration after changing models.py
```

Dont forget to review autogenerated migrations
